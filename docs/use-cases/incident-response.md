# Incident response

Use Okatana to coordinate an incident without impersonating a browser user.

A monitoring service can:

- list members for valid assignee IDs;
- create a `critical` ticket in an active board;
- assign a small response group;
- add the initial timeline comment;
- send organization notifications with an internal `/app` URL;
- move the ticket as the incident state changes;
- publish a post-incident document later.

Source example: `examples/incident-response.ts`.
